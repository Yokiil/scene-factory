# 完整姿态与实例物理参数

日期：2026-11-04。旧的 position + yaw 布局仍可读取；含完整姿态或实例参数的
`CompiledScene.to_dict()` 输出标记 `scene_factory.compiled_scene.v2`。
位置单位为米，四元数顺序为 **w,x,y,z**，表示物体坐标系到世界坐标系的主动旋转。

```json
{
  "position": [0.6, 0.13, 1.09],
  "orientation_wxyz": [0.7071067811865476, 0, 0.7071067811865476, 0]
}
```

四元数必须有限、单位化。显式 `yaw_deg` 若同时出现，必须与四元数推导出的平面航向一致；
不能用两个互相矛盾的字段描述姿态。旧数据由 yaw 转成绕世界 Z 轴的四元数：

```sh
python tools/migrate_scene_se3.py old/layout.json --output new/layout.json
```

工具保留原文件、对象和其他任务字段；重复升级不改变数值。它只升级位姿表示，不会
把一个桌面配方自动转换成可执行的装配任务。

当前执行路径：

- MuJoCo MJCF 和 Isaac USD 导出使用完整姿态。Blender 可视化清单也保留四元数。
- 房间边界、通道使用三维旋转后的保守包围盒；有倾斜的物体对使用三维 OBB 分离轴检查。
- 支撑和收纳检查在支撑物的本地坐标系中计算。几何通过不等于倾斜表面上的动力学稳定。
- 原抓杯转换器和 `around` 布局约束仍只支持直立物体，对倾斜输入明确报不支持。
- 语义 SceneIR 和配方布局器仍保持各自的能力边界，未知装配约束不会被静默执行。

实例 `physics` 覆盖通过类型化场景读写保留，不修改共享资产：质量 kg、对角惯量 kg·m²、
摩擦系数及来源。MuJoCo 与 Isaac 的动态基本几何导出支持此覆盖；引用 USD 的尺寸或
惯量重估需要专门适配，当前明确拒绝未经验证的缩放。真实引擎编译后的最终参数仍应记录
在运行证据中，不能只依赖输入清单。

`tests/test_pose_se3.py` 覆盖旧姿态迁移、重复升级、冲突/非单位四元数、三维边界与相对坐标。
仿真任务是否成功，以该任务对应的物理证据和验收报告为准。
