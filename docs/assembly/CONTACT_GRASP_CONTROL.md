# 接触反馈抓持控制

`tools/run_precision_assembly.py` 默认使用 `--grasp-control contact`。它先完成
闭爪、离桌、离桌后增压和稳定保持，再进入原有搬运与插接流程。每一步只发有界
关节位置目标；物体位姿、原始速度和冻结装配规格不作修改。

## 阶段条件

- 自由闭爪在接近夹具声明的零件宽度前减速，避免把高速驱动的跟踪滞后带入接触。
  首次接触后采用更低的目标变化速率，并限制目标相对实测指位的压入距离。
- 闭爪需要两侧接触力进入目标区间，且实测速度连续稳定，才允许微抬升。
- 微抬升保持当前夹持目标；只有零件实际升高、桌面接触力消失、双指仍接触并
  持续稳定，才能进入再收紧。TCP 运动或经过固定时间均不能代替该条件。
- 微抬升使用固定 warm start 的 IK 位移，加到原驱动目标上，保留受载时的静态
  补偿；不会在切换阶段时把测量位姿重新求解的关节值直接替换原目标。
- 离桌后逐步调整夹持目标，达到目标力与稳定窗口后输出 `ready`。
- 接触丢失会暂停增加抬升目标，持续丢失、TCP 坐标中的相对滑移、角速度保护、
  超力或阶段超时均停止当前试验。缺测、非有限值及不连续时间戳也会拒绝。
- 速度进入预警区时暂停闭爪和抬升，要求连续稳定后才恢复，恢复超时则失败。
  `recovery_open_speed_mps` 可显式请求受限开指回退；默认是 0，只保持目标。
  本轮开指回退试验未解决接触稳定性，不作为默认成功方案。

当前控制参数属于实验起点，保存在 `GraspControlConfig` 中。`--grasp-config`
接收只覆盖所需字段的 JSON；未知字段或无效阈值拒绝。控制保护值比原装配
验收门槛更保守，保护停止不会被算作任务成功。夹指速率使用运行时开闭行程换算。

## 短程诊断与完整运行

使用 Isaac 专用 Python、已有 ASCII 路径夹具及本机有授权的 Franka 资产：

```powershell
& $IsaacPython tools/run_precision_assembly.py $Fixture `
  --output $NewOutput --asset-root $AssetRoot --online --grasp-only `
  --grasp-height-m 1.01 --physics-dt-s 0.004166666666666667 `
  --physics-overrides $ExplicitPhysicsConfig `
  --finger-stiffness 1000 --finger-damping 100 --finger-max-force 20
```

`--grasp-only` 在抓持阶段达到 `ready` 后结束。该命令成功时
`grasp_prefix_acceptance=passed`，而 `assembly_acceptance=not_verified`；它没有执行
搬运、插入和释放。完整插接去掉 `--grasp-only`，仍由正式在线 evaluator 判定。
新输出目录避免覆盖旧证据。

`--grasp-control timed` 保留历史固定时间流程，用于对照。旧的
`--prelift-grip-fraction` 只适用于该模式；不能与接触反馈模式混用。

## 保存的证据

- `trace.jsonl`：每物理步原始零件状态、指位、TCP 位姿、接触和实际发送动作。
  启用 `--grasp-contact-details` 后，抓持阶段还会记录每个碰撞体的法向力、接触点、
  法向、间距，以及摩擦力向量和作用点。该选项只增加证据，不改变控制和验收。
- `grasp_control_trace.jsonl`：按 `input_time_s` 关联测量的控制决策及保护原因。
- `grasp_controller_source.py`、`grasp_control_config.json`：控制模块原始源码与实际配置，
  报告保存源码摘要；主脚本仍单独保存。
- `report.json`：抓持前缀结论、完整装配结论、未过滤速度审计与阶段摘要分别记录。
  摘要中的保护事件通过测量时间绑定，不回写原始轨迹。

纯 Python 测试验证传感器契约、状态转换和异常处理，不构成真实物理通过证据。
